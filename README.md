# 京阪・名古屋旅行手冊

開啟 `kansai.html` 即可查看新版手冊；`index.html` 也會導向同一頁。景點與行程可在沒有網路時閱讀；地圖底圖及外部導航、官方連結需要網路。

- 行程以去趣「京阪神 6 天 5 夜」為基礎，已於 2026/11/23 對照六天的景點順序與原列時間；按需求交換 12/5、12/6，12/6 可切換原京都行程及新增的名古屋展覽行程。依使用者更正補上每日住宿銜接、移除 12/7 11:00 的京都住宿中途站，12/8 改以 OMO 為最後住宿。去趣資料是當時快照，後續變動不會自動同步。
- `osaka.html` 是原版手冊（維持原網址、內容未更動），包含原本的詳細行前資訊及租車、住宿說明。由於原版與去趣有差異，以原版對照時須留意日期與安排可能已過時。
- 地圖實線為道路參考，虛線代表大眾運輸、接駁或待確認的路段示意；部分標記是附近參考位置，實際交通、地點與時間請透過連結核對。
- 路線總覽直接列出每天各站、交通與照片，編號如 `1-1` 表示第一天第一站；12/6 京都組以 `3京`、名古屋組以 `3名` 區分。總覽地圖的相近標記會合併，點選或放大可查看各站。
- 每站顯示實景照片並標註來源；可授權使用的照片另標明作者及授權，店家和住宿照片標明官方公開來源。尚無法確認店面照片的站點以附近實景代替並明確標示；官方住宿房型照片為示意，未必是實際預訂房型。
- 主時間依「前一站出發＋下一段交通」計算。一般行程點停留 1 小時；伏見稻荷、清水寺及貴船神社各 2 小時，12/8 各行程點 3 小時，賽馬看到第 3 場。住宿出發與終點、純轉乘及中途取車依各站明示的緩衝計算；名古屋展場按 11:00 開放後參觀 1 小時。跨午夜會顯示實際日期。
- 每段交通主要依 Google 地圖於 2026/11/25 查得的路線與時間；天橋立吊椅各 6 分依官方資料，關西空港站至第一航廈步行 5 分為規劃估計。這些不是即時或出發日預測；除已標示的緩衝外，停車、候車及排隊等額外時間未計入。各段連結可查當日路況；租車門市範例仍須與訂單核對。
- 地圖優先使用 OpenFreeMap 底圖，無法載入時改用日本國土地理院的地理院タイル；如網路或服務異常，頁面仍保留景點清單及各段導航連結。
- 12/4 首站加入 HanaCell 官方關西機場領卡位置圖，12 月起的櫃台位於關西空港站 2F 改札口外；營業及領取規則請以官方最新公告為準。
- 12/4 晚間新增飛田新地，位置以飛田會館附近作參考，照片為 2009 年街景；12/5 早上新增阪神競馬場與現場觀賽指南。一般入場免費、停車另計；賽事時間、入場及停車細節查核至 2026/11/25，出發前請再看 JRA 最新公告。未逐場核實的賽程明確標註，並非認定尚未公布。
- 12/5 安排看完第 3 場、假設 11:10 取車離開；依原順序每站停 1 小時，INE CAFE 與舟屋食堂會在關門後才到，需調整順序或停留。單軌／吊椅末班與實際候車也須確認。
- 12/8 京都住宿 09:20 步行出發，勝林寺約 09:44 抵達、10:00 起停留 3 小時；寺方沒有汽車停車場，10:00 一般參拜是否開放請先確認。依各行程點 3 小時及原順序推算將跨到 12/9 10:05 才回 OMO，與原手冊參考的 12/8 17:00 還車和 12/9 回程航班衝突，此為數學推算而非可執行方案。
- 名古屋展覽官方參加名單及 IG 配對查核至 2026/11/23；IG 清單區分主辦方／品牌提供、公開資料配對及同名待確認，尚未確認不等於沒有帳號。名古屋場優先入場與票價未確認，請以主辦方最新公告為準。
- `assets/itinerary.js` 是行程資料；`assets/transport.js` 是交通方式與查詢快照；`assets/schedule.js` 定義各站停留、轉乘緩衝與逐站時間計算。`assets/routes-extra.js` 為 OSRM／OpenStreetMap 自駕道路參考線；`assets/dealers.js` 是官網攤商名單及 IG。可執行 `node --test tests/schedule.test.cjs` 驗證時間與跨日計算。
