# 京阪・名古屋旅行手冊

開啟 `kansai.html` 即可查看新版手冊；`index.html` 也會導向同一頁。景點與行程可在沒有網路時閱讀；地圖底圖及外部導航、官方連結需要網路。

- 行程以去趣「京阪神 6 天 5 夜」為基礎，已於 2026/11/23 對照六天的景點順序與原列時間；按需求交換 12/5、12/6，12/6 可切換原京都行程及新增的名古屋展覽行程。內容是當時快照，後續變動不會自動同步。
- `osaka.html` 是原版手冊（維持原網址、內容未更動），包含原本的詳細行前資訊及租車、住宿說明。由於原版與去趣有差異，以原版對照時須留意日期與安排可能已過時。
- 地圖實線為道路參考，虛線代表大眾運輸、接駁或待確認的路段示意；部分標記是附近參考位置，實際交通、地點與時間請透過連結核對。
- 路線總覽以顏色與編號區分每天，地圖下方列出各日日期及主要區域；12/6 京都與名古屋分組各有顏色，點選即可切換。
- 每站顯示實景照片並標註來源；可授權使用的照片另標明作者及授權，店家照片標明公開來源。尚無法確認店面照片的站點以附近實景代替並明確標示；住宿照片顯示本機訂房畫面中的房型。
- 每段交通顯示開車、步行、電車或地鐵等建議，並補充停車與取車動線。去趣原列時間不一定適用於新增的交通建議，出發前請查導航與班次。
- 地圖優先使用 OpenFreeMap 底圖，無法載入時改用日本國土地理院的地理院タイル；如網路或服務異常，頁面仍保留景點清單及各段導航連結。
- 12/4 首站加入 HanaCell 官方關西機場領卡位置圖，12 月起的櫃台位於關西空港站 2F 改札口外；營業及領取規則請以官方最新公告為準。
- 名古屋展覽官方參加名單及 IG 配對查核至 2026/11/23；IG 清單區分主辦方／品牌提供、公開資料配對及同名待確認，尚未確認不等於沒有帳號。名古屋場優先入場與票價未確認，請以主辦方最新公告為準。
- `assets/itinerary.js` 是行程資料；`assets/dealers.js` 是官網攤商名單及 IG；`assets/vendor/leaflet/` 含地圖函式庫及其授權文件。
